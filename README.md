# 🏃 Site Corrida

Site estático sobre corrida, com informações de treinos, dicas e contato.

## Páginas

- `index.html` — página inicial, com boas-vindas, benefícios da corrida, dicas rápidas e próximos eventos
- `treinos.html` — planos de treino para diferentes níveis (iniciante 5km, intermediário 10km e avançado 21km), com descrição de cada nível, frequência semanal recomendada e dicas específicas
- `sobre.html` — sobre o site e informações de contato (email e Instagram)

## Tecnologias

- HTML5
- CSS3
